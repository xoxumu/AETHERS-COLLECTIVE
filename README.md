# AETHERS COLLECTIVE — подарки Telegram

Адаптивный статический сайт для презентации услуги по покупке коллекционных подарков Telegram. Проект состоит из HTML, CSS, JavaScript и локальных изображений в папке `assets/`; сборка не требуется.

## Файлы

- `index.html` — структура сайта и текстовые разделы.
- `styles.css` — Liquid Glass оформление, адаптивная сетка и мобильные стили.
- `palette.css` — бело-голубая тема, стеклянные поверхности, цвета текста и плавная анимация бегущей строки.
- `script.js` — мобильное меню, диалог предложения подарка и подготовка сообщения для Telegram.
- `assets/aethers-emblem.png` — присланная закруглённая эмблема AETHERS COLLECTIVE для шапки, подвала и иконки вкладки.
- `assets/aethers-logo.png` — исходное полное изображение логотипа, сохранённое без изменения качества.
- `.nojekyll` — GitHub Pages отдаёт статические файлы без обработки Jekyll.
- `.gitignore` — исключает системные файлы и локальные логи.
- `assets/` — оригинальные референсы подарков, переданные hero- и collection-изображения, эмблема и фон сайта в исходном качестве.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в его корень файлы проекта: `index.html`, CSS, JavaScript, `README.md`, `.nojekyll` и папку `assets/`.
2. В репозитории открой **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**, затем ветку по умолчанию и папку `/(root)`.
4. Сохрани настройки. После публикации GitHub Pages покажет адрес сайта.

Сборщик и серверная часть не нужны. Пути к страницам и изображениям относительные, поэтому сайт работает и в корне репозитория, и как проектный GitHub Pages-сайт. Форма готовит черновик и открывает Telegram Share; сообщение пользователь проверяет и отправляет сам. Кнопка поддержки ведёт в Telegram-бота `@Aethers_HelpBot`.
