# AETHERS COLLECTIVE — NFT Telegram

Адаптивный статический сайт для презентации услуги по покупке коллекционных NFT Telegram. Проект состоит из HTML, CSS, JavaScript и локальных изображений в папке `assets/`; сборка не требуется.

## Файлы

- `index.html` — структура сайта, SEO-разметка, фильтруемый каталог и заявки.
- `styles.css` — Liquid Glass оформление, адаптивная сетка и мобильные стили.
- `palette.css` — бело-голубая тема, Liquid Glass поверхности, округлая типографика и стили новых карточек/форм.
- `script.js` — мобильное меню, фильтры каталога, проверка заявки, копирование текста и переключение «Банк / Поддержка».
- `assets/aethers-emblem.png` — присланная закруглённая эмблема AETHERS COLLECTIVE для шапки, подвала и иконки вкладки.
- `assets/aethers-logo.png` — исходное полное изображение логотипа, сохранённое без изменения качества.
- `.nojekyll` — GitHub Pages отдаёт статические файлы без обработки Jekyll.
- `.gitignore` — исключает системные файлы и локальные логи.
- `assets/` — оригинальные референсы NFT, переданные hero- и collection-изображения, эмблема и фон сайта в исходном качестве.

## Публикация

Исходники хранятся в публичном репозитории [xoxumu/AETHERS-COLLECTIVE](https://github.com/xoxumu/AETHERS-COLLECTIVE). Сайт опубликован через GitHub Pages: <https://xoxumu.github.io/AETHERS-COLLECTIVE/>.

Для поисковых роботов добавлены `robots.txt` и `sitemap.xml`. Индексация поисковыми системами происходит не сразу и не гарантируется одной только публикацией.

Сборщик и серверная часть не нужны. Пути к страницам и изображениям относительные, поэтому сайт работает и в корне репозитория, и как проектный GitHub Pages-сайт. Форма собирает заявку на странице, по отдельному нажатию копирует её в буфер и открывает Telegram-бота без заготовленного текста. `robots.txt` и `sitemap.xml` помогают поисковым системам находить страницу; индексация Google не гарантируется одной только публикацией.
